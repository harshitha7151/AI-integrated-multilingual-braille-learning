# Dataset research for Resonant AIML

**Reviewed:** 2026-11-22  
**Scope:** Public source pages/papers were reviewed. The small UCI CLINC150 archive and corrected ASSISTments 2009-2010 Skill Builder CSV were downloaded locally, schema-checked, hashed, and evaluated in their documented experiments. Other archives remain undownloaded. “Available” for those datasets means the primary source describes an access path, not that a local copy or schema has been tested.

## Summary and fit

No reviewed public dataset represents Resonant's English, Hindi, or Kannada Braille practice events. Public education datasets can test generic learning analytics methods; generic intent datasets can test text-classification mechanics. Neither is a substitute for consented Resonant data or evidence of Braille-learning effectiveness.

## Intent-label applicability

The eventual Resonant label set should be derived from actual product routes and reviewed support policy, not copied from an external corpus. Candidate labels for annotation include deterministic mapping request, dot explanation, lesson concept, practice hint, mistake explanation, progress/navigation support, supported Braille-learning question, and out-of-scope/clarification. Mapping intent must still dispatch to deterministic engines regardless of classifier output.

MASSIVE and CLINC150 can measure whether a pipeline trains, separates classes, and rejects some out-of-domain inputs on their own official tasks. They cannot answer whether Resonant recognizes a learner asking in English, Hindi, or Kannada about Bharati Braille. Hindi/Kannada Resonant examples must be authored or collected with qualified language reviewers and blind/low-vision learner/community input; authored examples must be explicitly tagged as authored. Any real query collection needs purpose-specific consent, privacy review, and a process for correcting labels.

## Reproducible acquisition policy

- Do not commit raw archives. Record canonical URL, dataset revision/date, license file, download checksum, acquisition date, and preprocessing script.
- Keep immutable source data separate from derived data; publish derived data only if the original terms allow it.
- Preserve official train/validation/test splits for benchmark replication. Deduplicate by normalized text only as a documented check; never move or tune on the test set.
- For learner interaction datasets, keep learner identifiers only in split/grouping metadata and remove them from feature matrices.
- Do not use a non-commercial corpus in a commercial deployment without separate permission. Obtain legal review when intended use or model redistribution is unclear.

## Sources checked

- MASSIVE paper: FitzGerald et al. (2023), ACL Anthology, above; official Amazon Science page and GitHub notice establish domain, language coverage, access and CC BY 4.0 terms.
- CLINC150 paper: Larson et al. (2019), ACL Anthology, above; authors' repository establishes official data splits and OOS structure.
- OULAD: Kuzilek, Hlosta & Zdrahal (2017), *Scientific Data* 4, 170171, DOI above; official OU page provides download entry.
- EdNet: Choi et al. (2020), arXiv:1912.03072; official Riiid GitHub README provides dataset schema, downloadable subset sizes, and license statement.
- ASSISTments 2017: official dataset/competition pages above; the access restriction is why local availability and schema are not asserted.
- ASSISTments 2009-2010: official corrected release page and current E-TRIALS terms above; verified local statistics and measured results are in `../experiments/assistments_2009_2010/README.md` and `../reports/assistments_2009_2010/`.
- Braille EEG: official NEMAR/OpenNeuro records above. It is included to distinguish Braille signal research from learner modeling, not recommended as a Resonant training set.
