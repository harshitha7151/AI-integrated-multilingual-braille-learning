Explore Resonant AIML concepts

Live, deterministic, rule-based and experimental components are separated below. Click a concept to expand its plain-language and technical explanation.

Deterministic

Braille encoding & validation

Verified language tables produce cells and check learner input. They do not learn from examples or predict a mapping.

lib/core/braille/ ? resonant_backend/verified_braille.py

Deterministic

Voice command resolution

Known navigation and assessment commands are parsed and validated against current app state. Live mobile navigation does not use the CLINC150 classifier.

lib/tutor/voice_command_parser.dart ? lib/tutor/tutor_action_controller.dart

Rule-based

Adaptive learning

The production recommender uses learner progress rules. Experimental model work is not presented as the live recommendation path.

resonant_backend/recommendation_service.py ? resonant_backend/assessment_service.py

Live when used

AI Tutor & local model

Tutor questions may reach the FastAPI tutor and configured Ollama model; deterministic commands and verified Braille mapping can resolve without an LLM. Actual received stages appear in the event feed.

lib/tutor/voice_tutor_controller.dart ? resonant_backend/main.py

Experimental

TF-IDF + Logistic Regression

TF-IDF converts text into sparse numeric features. The saved classifier is trained on CLINC150, an English general-assistant dataset, and does not control live Resonant commands.

aiml/artifacts/tfidf_logistic_regression.joblib ? aiml/reports/intent_clinc150/

Experimental

Linear SVM & calibration

The comparison runs saved Python pipelines. Raw Linear SVM decision margins are not probabilities; the calibrated model exposes calibrated class probabilities. Results apply only to this experiment.

aiml/artifacts/tfidf_linear_svm.joblib ? aiml/artifacts/tfidf_calibrated_linear_svm.joblib

Platform services

Speech & spoken output

Android speech recognition and Flutter TTS are platform services. The microphone is learner-invoked or settings-governed; laptop visuals only reflect events the phone actually sends.

lib/tutor/speech_to_text_recognizer.dart ? lib/main.dart

Evaluation

Dataset & model evaluation

Use the inventory panel for actual split counts and saved report metrics. No model is trained when this page opens. The input playground calls saved pipelines only.

aiml/reports/intent_clinc150/metrics.json
